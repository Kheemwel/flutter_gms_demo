# Flutter GMS Demo (FLAGMS Port)

This project is a Dart and Flutter port of my original capstone project named FLAGMS. You can check out the original repository here: https://github.com/Kheemwel/FLAGMS.

## Why I made this

I made this because I wanted a way to showcase my capstone project. The original project had no easy way to run or show even just the front-end, so I made this version without a backend. It just uses dummy data stored in memory.

## Why Dart and Flutter

I chose Dart and Flutter because I wanted to experience how they are used in this kind of project. I also have some regrets about the tech stack I chose for the original project, and I know I used those tools the wrong way too. I want to move on and use a tech stack that I actually like and love from now on, so I chose Dart and Flutter.

## Differences from the original

- Some features and modules are not ported or implemented yet.
- I didn't faithfully copy the original UI, assets, or the client/school's name.
- I used Material Design because why not? It's already built into Flutter, so I didn't need to pick another UI library when a good default is already there.

## Future plans

I also want to make this project an agnostic guidance management system instead of just a port, though there is a 90% chance I might not actually do it.
